## ℹ️ Overview
This project is a handwritten digit recognition neural network built  using Python and NumPy.

The network takes 28×28 images as input, processes them through 1 hidden layer, and outputs a prediction on what it estimates the digit to be. It uses forward propagation, backpropagation and gradient descent to learn from training data.

The goal of this project was to explore and learn how neural networks work, from things like initialising weights, training and prediction, without relying on ML frameworks like TensorFlow or PyTorch.
